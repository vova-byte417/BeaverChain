## 📋 前置准备

在开始之前，请确保：

1. ✅ 你已经成功安装了 BeaverChain（参考 [安装指南](installation.md)）
2. ✅ 你可以访问 Web 控制台：`http://localhost:3000`
3. ✅ 你已经登录系统（默认账号：`admin@beaverchain.ai` / `admin123`）

## 第一步：创建你的第一个模型版本

### 1.1 进入模型版本管理页面

1. 登录后，点击左侧导航栏的 **「模型版本」**
2. 点击右上角的 **「+ 创建版本」** 按钮

### 1.2 填写基本信息

```
版本名称: my-first-model
描述: 我的第一个大模型版本
标签: demo, tutorial
```

### 1.3 配置 Prompt 模板

在 Prompt 配置区域输入：

```
你是一个专业的技术支持助手，名叫 Beaver。

请遵循以下规则回答用户问题：
1. 始终保持友好和专业的语气
2. 如果不确定答案，请诚实说明，并建议其他解决方案
3. 对于技术问题，尽量给出具体的操作步骤
4. 回答简洁明了，重点突出

用户问题: {{user_query}}

请回答:
```

> 💡 **提示**: 使用 `{{变量名}}` 语法定义占位变量，调用时可以动态传入值。

### 1.4 配置推理参数

```
温度 (Temperature): 0.7
Top P: 0.9
最大 Token 数: 1024
停止序列: ["\n\n", "用户:"]
```

### 1.5 保存版本

点击 **「创建版本」** 按钮。

🎉 恭喜！你已经创建了第一个模型版本！

---

## 第二步：测试 Prompt 效果

### 2.1 进入 Prompt 测试页面

1. 在模型版本详情页，点击 **「测试 Prompt」** 标签
2. 你会看到刚才配置的 Prompt 模板

### 2.2 填写变量值

在变量输入框中输入：

```json
{
  "user_query": "如何重置密码？"
}
```

### 2.3 运行测试

点击 **「运行测试」** 按钮，查看模型输出。

预期输出应该类似于：

```
您好！重置密码的步骤如下：

1. 访问登录页面
2. 点击 "忘记密码" 链接
3. 输入您的注册邮箱
4. 查收重置密码邮件
5. 点击邮件中的链接设置新密码

如果在操作过程中遇到任何问题，请随时联系我们的客服团队。
```

### 2.4 保存测试结果

点击 **「保存为测试用例」**，以便后续进行回归测试。

## 第三步：配置 RAG 知识库

### 3.1 创建知识库

1. 点击左侧导航栏的 **「知识库」**
2. 点击 **「+ 创建知识库」**
3. 填写信息：

```
知识库名称: 产品文档
描述: 公司产品文档和 FAQ
语言: 中文
```

### 3.2 上传文档

1. 在知识库详情页，点击 **「添加文档」**
2. 选择以下方式之一上传文档：
   - **上传文件**: 支持 PDF、Word、Markdown、TXT
   - **输入文本**: 直接粘贴文本内容
   - **网页抓取**: 输入 URL 自动抓取

让我们创建一个简单的文本文档：

```
标题: 密码重置流程

内容:
密码重置流程如下：
1. 用户访问登录页面
2. 点击 "忘记密码" 链接
3. 输入注册邮箱地址
4. 系统发送重置邮件
5. 用户点击邮件中的重置链接
6. 设置新密码并确认

注意事项：
- 重置链接有效期为 24 小时
- 新密码必须包含大小写字母和数字
- 连续 5 次失败后账户会被锁定 30 分钟
```

### 3.3 向量化处理

1. 上传文档后，系统会自动进行向量化处理
2. 等待状态变为 **「已就绪」**
3. 点击 **「测试检索」** 验证效果

测试查询：`如何重置密码？`

预期结果应该返回刚才上传的密码重置文档。

### 3.4 关联到模型版本

1. 返回模型版本详情页
2. 在 RAG 配置区域选择刚才创建的知识库
3. 保存配置

现在模型回答时会自动检索知识库内容！

## 第四步：构建工作流

### 4.1 理解工作流概念

工作流（Workflow）允许你将多个步骤串联起来，构建复杂的处理流程。

常见的节点类型：
- **LLM 节点**: 调用大模型
- **条件节点**: 根据条件分支
- **检索节点**: 从知识库检索
- **工具节点**: 调用外部工具
- **合并节点**: 合并多个分支结果

### 4.2 创建第一个工作流

1. 点击左侧导航栏的 **「工作流编排」**
2. 点击 **「+ 创建工作流」**
3. 填写信息：

```
工作流名称: 智能客服流程
描述: 处理用户技术支持请求的完整流程
```

### 4.3 设计工作流

在画布上拖拽并连接以下节点：

```
[开始]
   ↓
[意图识别 LLM] → 分析用户问题类型
   ↓
[条件判断] ── [技术问题] → [检索知识库] → [生成回答 LLM] → [结束]
          │
          └─ [其他问题] → [转人工客服] → [结束]
```

#### 节点 1: 意图识别

```
节点类型: LLM 节点
名称: 意图识别
模型版本: my-first-model@v1.0
Prompt:
请分析用户问题的意图，只能回复以下选项之一：
- 技术问题
- 账户问题
- 产品咨询
- 其他问题

用户问题: {{user_query}}

意图:
```

#### 节点 2: 条件判断

```
节点类型: 条件节点
名称: 问题分类
条件:
如果 {{意图识别.output}} == "技术问题" → 走"技术问题"分支
否则 → 走"其他问题"分支
```

#### 节点 3: 检索知识库

```
节点类型: 检索节点
名称: 查找相关文档
知识库: 产品文档
查询: {{user_query}}
Top K: 3
```

#### 节点 4: 生成回答

```
节点类型: LLM 节点
名称: 生成回答
模型版本: my-first-model@v1.0
Prompt:
请根据以下上下文回答用户问题。

上下文:
{{查找相关文档.output}}

用户问题: {{user_query}}

请用友好、专业的语气回答：
```

### 4.4 测试工作流

1. 点击右上角的 **「测试运行」**
2. 输入测试用例：

```json
{
  "user_query": "密码忘记了怎么办？"
}
```

3. 点击 **「运行」**，观察每个节点的执行结果

## 第五步：查看评估指标

### 5.1 进入评估面板

1. 点击左侧导航栏的 **「评估监控」**
2. 你会看到核心指标概览：

```
📊 核心指标
────────────────────────────
幻觉率: 2.3%  ↓ 0.5%  ✅
毒性评分: 0.05  ✅
忠实度: 95.2%  ✅
平均延迟: 320ms  ✅
```

### 5.2 查看详细报告

1. 点击 **「幻觉率」** 指标
2. 查看被检测出幻觉的具体案例
3. 可以对案例进行标注，用于模型改进

### 5.3 设置告警

1. 点击右上角的 **「告警设置」**
2. 配置告警规则：

```
指标: 幻觉率
阈值: > 5%
连续触发: 3 次
通知方式: 邮件 + 飞书
```

## 第六步：版本管理与回滚

### 6.1 创建新版本

1. 在模型版本详情页，点击 **「创建新版本」**
2. 修改 Prompt 模板或参数
3. 保存为 v1.1 版本

### 6.2 版本对比

1. 在版本列表页，选择两个版本
2. 点击 **「对比版本」**
3. 查看差异：

```diff
--- v1.0
+++ v1.1
@@ -5,6 +5,7 @@
 请遵循以下规则回答用户问题：
 1. 始终保持友好和专业的语气
 2. 如果不确定答案，请诚实说明
+3. 对于常见问题，建议用户先查看 FAQ
```

### 6.3 版本回滚

如果新版本有问题：

1. 在版本列表中找到 v1.0
2. 点击 **「回滚到此版本」**
3. 确认操作

系统会自动将生产环境切换回 v1.0 版本。
