## 基础概念

### 什么是 BeaverChain？

BeaverChain 是一个一站式大模型构建平台，帮助团队高效管理从模型版本化到部署运维的完整流程。

### 核心概念

| 概念 | 说明 |
|------|------|
| **模型版本 (Model Version)** | 包含 weights、prompt、RAG 配置、Guardrails 规则的完整快照 |
| **版本状态** | draft（草稿）→ testing（测试）→ staging（预发）→ production（生产）→ archived（归档） |
| **Prompt 模板** | 可复用的提示词模板，支持变量占位符 |
| **RAG 知识库** | 检索增强生成的知识来源 |
| **工作流 (Workflow)** | 多个步骤组成的复杂处理流程 |
| **血缘 (Lineage)** | 版本之间的衍生关系和历史追踪 |

## 模型版本管理

### 创建模型版本

1. 点击左侧导航栏 **「模型版本」**
2. 点击右上角 **「+ 创建版本」**
3. 填写基本信息：
   - **名称**：唯一标识，建议用小写字母和连字符，如 `customer-support`
   - **版本号**：遵循语义化版本，如 `1.0.0`、`1.0.1-beta`
   - **描述**：简要说明这个版本的用途和特性
   - **标签**：便于分类和检索，如 `production`、`experiment`
4. 配置各个组件（见下文详细说明）
5. 点击 **「创建版本」**

### 版本状态流转

```
draft (草稿)
  ↓
testing (测试中) ← 回滚
  ↓
staging (预发) ← 回滚
  ↓
production (生产) ← 回滚
  ↓
archived (归档)
```

**状态说明：**
- **draft**: 编辑中，不可用于生产调用
- **testing**: 测试中，可用于测试环境
- **staging**: 预发布，可用于灰度验证
- **production**: 生产环境，稳定可用
- **archived**: 已归档，不再使用，但保留历史

### 版本对比

1. 在版本列表中，勾选需要对比的两个版本
2. 点击 **「对比版本」**
3. 查看差异：
   - 🟢 绿色：新增内容
   - 🔴 红色：删除内容
   - 🟡 黄色：修改内容
4. 可以只查看特定组件的差异（Prompt、RAG 配置等）

### 版本回滚

**方法一：创建新版本回滚（推荐）**
1. 找到需要回滚到的历史版本
2. 点击 **「基于此版本创建新版本」**
3. 填写新版本号，如 `1.0.2-rollback`
4. 保留变更记录，便于审计

**方法二：原地回滚**
1. 找到当前版本
2. 点击 **「回滚」**
3. 选择目标版本
4. 填写回滚原因
5. ⚠️ 注意：原地回滚会覆盖当前版本，建议谨慎使用

### 版本历史查询

1. 进入版本详情页
2. 点击 **「历史记录」** 标签
3. 可以看到：
   - 所有变更记录
   - 每次变更的用户
   - 变更时间
   - 变更内容对比

## Prompt 管理

### Prompt 编辑器

#### 基本功能
- **语法高亮**：变量自动高亮显示
- **实时预览**：编辑时实时查看渲染效果
- **变量检测**：自动检测 `{{变量名}}` 形式的变量
- **格式化**：一键格式化，自动缩进

#### 高级功能
- **条件渲染**：支持 `{% if 条件 %}...{% endif %}` 语法
- **循环遍历**：支持 `{% for item in 列表 %}...{% endfor %}`
- **模板继承**：支持 `{% extends 基础模板 %}` 复用基础模板

### Prompt 变量

#### 定义变量
```
你是一个 {{role}} 助手，专门回答 {{topic}} 相关问题。

用户问题：{{user_query}}

请回答：
```

#### 设置变量默认值
在变量管理面板中，可以为每个变量设置默认值：
- `role`: "专业的"
- `topic`: "技术"

### Prompt 分支管理

#### 创建分支
1. 在 Prompt 编辑器中点击 **「创建分支」**
2. 填写分支名称，如 `feature/more-friendly`
3. 基于当前版本创建新分支

#### 合并分支
1. 点击 **「合并分支」**
2. 选择要合并的源分支和目标分支
3. 查看合并差异
4. 解决冲突（如有）
5. 确认合并

### A/B 测试

#### 创建实验
1. 准备两个不同的 Prompt 版本
2. 进入 **「A/B 测试」** 页面
3. 点击 **「创建实验」**
4. 设置实验参数：
   - 实验名称
   - 版本 A 和版本 B
   - 流量分配比例（如 50% / 50%）
   - 实验时长
5. 启动实验

#### 查看实验结果
- 关键指标对比（用户满意度、完成率等）
- 统计显著性分析
- 自动推荐优胜版本

## RAG 知识库

### 创建知识库

1. 点击左侧导航栏 **「知识库」**
2. 点击 **「+ 创建知识库」**
3. 填写信息：
   - **知识库名称**：如 `产品文档`、`技术手册`
   - **描述**：知识库的用途和内容范围
   - **语言**：中文 / English / 多语言
   - **向量化模型**：选择用于嵌入的模型

### 添加文档

#### 方式一：上传文件
支持的文件格式：
- 📄 PDF 文档
- 📝 Word 文档 (.docx)
- 📑 Markdown (.md)
- 📄 纯文本 (.txt)
- 📊 PowerPoint (.pptx) - 提取文本内容

#### 方式二：直接输入文本
1. 选择 **「文本输入」**
2. 填写文档标题和内容
3. 点击 **「添加」**

#### 方式三：网页抓取
1. 选择 **「网页抓取」**
2. 输入 URL（支持多个 URL 批量导入）
3. 选择抓取深度
4. 点击 **「开始抓取」**

### 文档处理

#### 分块策略
- **固定长度**：每块 512/1024 Token（默认）
- **语义分块**：智能识别内容边界，保持语义完整
- **自定义**：根据文档结构自定义分块规则

#### 向量化处理
文档上传后会自动进行：
1. 文本清洗和预处理
2. 智能分块
3. 向量化嵌入
4. 存入向量数据库

**处理状态：**
- 🟡 处理中：正在进行向量化
- ✅ 已就绪：可以正常使用
- ❌ 失败：处理出错，可重试

### 检索配置

#### 检索参数
- **Top K**: 返回最相关的前 K 个文档块（默认 3）
- **相似度阈值**: 最低相似度要求（默认 0.7）
- **重排序 (Rerank)**: 使用交叉编码器重新排序结果

#### 高级设置
- **元数据过滤**：根据标签、来源、创建时间过滤
- **混合检索**：结合关键词检索和向量检索
- **上下文压缩**: 智能压缩检索到的上下文

## Guardrails 安全护栏

### 安全规则配置

#### 毒性过滤
控制模型输出的毒性级别：
```
阈值设置: 0.0 - 1.0
- 宽松: 0.7 (允许少量负面情绪)
- 中等: 0.5 (默认，平衡安全和自然)
- 严格: 0.3 (高度安全，可能影响输出自然度)
```

检测类别：
- 🔴 辱骂和人身攻击
- 🔴 仇恨言论和歧视
- 🔴 色情内容
- 🔴 暴力和血腥
- 🟡 轻度负面情绪
- 🟡 争议性话题

#### 敏感词管理
- **内置黑名单**：预设的敏感词库
- **自定义黑名单**：添加企业特定的敏感词
- **白名单**：例外允许的词汇
- **正则匹配**：支持正则表达式模式匹配

#### 幻觉检测
- **事实一致性检查**: 验证输出与已知事实的一致性
- **自一致性验证**: 多次采样，检测输出矛盾
- **来源标注**: 强制模型标注信息来源

### 输出格式验证

#### JSON 格式验证
确保模型输出是有效的 JSON：
```json
{
  "answer": "这是回答内容",
  "confidence": 0.95,
  "sources": ["doc1", "doc2"]
}
```

#### 自定义 Schema
定义输出的字段和类型：
```
{
  "required": ["answer", "confidence"],
  "fields": {
    "answer": "string",
    "confidence": "float (0-1)",
    "sources": "array of strings"
  }
}
```

### 规则版本化
安全规则也支持版本化管理：
- 每次修改自动创建新版本
- 支持版本对比和回滚
- 规则变更有完整审计日志

## 工作流编排

### 工作流编辑器

#### 界面介绍
```
┌─────────────────────────────────────────────────────────┐
│  工具栏  [保存] [运行] [设置] [导入] [导出]           │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│  节点库      │              画布区域                    │
│  ┌──────┐   │                                          │
│  │ LLM  │   │    ┌─────┐     ┌─────┐     ┌─────┐   │
│  ├──────┤   │    │开始 │ ──▶ │处理 │ ──▶ │结束 │   │
│  │条件  │   │    └─────┘     └─────┘     └─────┘   │
│  ├──────┤   │                                          │
│  │检索  │   │                                          │
│  └──────┘   │                                          │
└──────────────┴──────────────────────────────────────────┘
```

#### 基本操作
- **添加节点**：从左侧拖拽到画布
- **连接节点**：拖拽节点输出口到下一个节点的输入口
- **删除节点**：选中节点按 Delete 键
- **移动节点**：拖拽移动
- **缩放画布**：Ctrl + 滚轮

### 节点类型详解

#### 1. LLM 节点
调用大模型进行处理。

**配置项：**
- 模型版本选择
- Prompt 模板（支持引用上游节点输出）
- 推理参数覆盖
- 输出变量映射

**示例：**
```
输入: {{检索节点.output}}
用户问题: {{开始节点.user_query}}

请根据检索结果回答用户问题：
```

#### 2. 条件节点
根据条件进行分支。

**条件表达式：**
```javascript
// 简单比较
意图识别.output == "技术问题"

// 复杂逻辑
评分 > 0.8 && 长度 < 1000

// 正则匹配
用户输入.match(/^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$/)
```

#### 3. 检索节点
从知识库检索相关内容。

**配置：**
- 选择知识库
- 设置 Top K 和阈值
- 配置查询模板（默认使用 `{{user_query}}`）

#### 4. 工具节点
调用外部工具或 API。

**内置工具：**
- 🔍 网页搜索
- 🧮 计算器
- 📅 日期时间
- 🌐 HTTP 请求

**自定义工具：**
支持通过 OpenAPI Schema 导入自定义工具。

#### 5. 代码节点
执行自定义 Python 或 JavaScript 代码。

**示例 (Python)：**
```python
# 输入: 上游节点输出作为变量
text = 上游节点.output

# 处理逻辑
word_count = len(text.split())
summary = text[:100] + "..." if len(text) > 100 else text

# 返回结果（自动传递到下游）
return {
    "word_count": word_count,
    "summary": summary
}
```

#### 6. 子工作流节点
嵌套调用其他工作流，实现模块化复用。

### 工作流调试

#### 测试运行
1. 点击 **「测试运行」**
2. 填写输入参数
3. 查看执行结果

#### 执行可视化
- 🟢 绿色节点：执行成功
- 🟡 黄色节点：执行中
- 🔴 红色节点：执行失败

可以逐步骤回放执行过程，查看每个节点的：
- 输入数据

- 输出结果
- 执行耗时

## 评估与监控

### 核心指标

#### 质量指标
| 指标 | 说明 | 目标值 |
|------|------|-------|
| **幻觉率** | 模型编造虚假信息的比例 | < 5% |
| **毒性评分** | 输出内容的有害程度 | < 0.1 |
| **忠实度** | 回答忠实于上下文的比例 | > 90% |
| **相关性** | 回答与问题相关的比例 | > 95% |

#### 性能指标
| 指标 | 说明 | 目标值 |
|------|------|-------|
| **平均延迟** | 从请求到响应的时间 | < 500ms |
| **P95 延迟** | 95% 请求的响应时间 | < 1000ms |
| **吞吐量** | 每秒处理的请求数 | > 100 |
| **错误率** | 请求失败的比例 | < 1% |

#### 成本指标
| 指标 | 说明 |
|------|------|
| **Token 消耗** | 输入 + 输出 Token 总数 |
| **平均每次成本** | 按 API 费率计算的平均成本 |
| **预算使用率** | 当期预算使用比例 |

### 告警配置

#### 创建告警规则
1. 进入 **「监控」→「告警设置」**
2. 点击 **「+ 添加规则」**
3. 配置：
   - **指标**：选择要监控的指标
   - **阈值**：触发条件（如 > 5%）
   - **持续时间**：连续 N 次触发才告警
   - **告警级别**：信息 / 警告 / 严重 / 紧急
   - **通知方式**：邮件 / 飞书 / Slack / Webhook

#### 告警通知示例
```
🔴 [严重] 幻觉率超过阈值
时间: 2026-05-12 14:30:00
指标: hallucination_rate
当前值: 6.8%
阈值: > 5%
持续: 5 分钟
建议: 检查最近的 Prompt 变更，考虑回滚到上一版本
```

### 自定义仪表盘

#### 添加图表
1. 点击 **「添加图表」**
2. 选择图表类型：
   - 折线图：趋势变化
   - 柱状图：对比分析
   - 饼图：占比分布
   - 数字卡片：关键指标
   - 表格：详细数据

#### 配置数据源
- 时间范围：今天 / 7 天 / 30 天 / 自定义
- 聚合方式：平均值 / 最大值 / 百分位数
- 分组维度：按模型版本 / 按时间段

## 团队协作

### 项目管理

#### 创建项目
1. 点击左上角项目名称 → **「创建新项目」**

   - **访客**：有限访问

### 评论与协作

#### 在版本中评论
1. 进入版本详情
2. 选中任意文本或配置
3. 添加评论
